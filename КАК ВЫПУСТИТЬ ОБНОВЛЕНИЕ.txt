АВТООБНОВЛЕНИЕ СТРАЖА — как это работает
=========================================

Страж раз в 6 часов заглядывает в ваш репозиторий github.com/Sve1kkk/Strazh:
  • если там есть новая версия — скачивает, проверяет контрольную сумму SHA-256,
    заменяет себя и перезапускается (если окно открыто — сначала спросит);
  • заодно скачивает свежую базу угроз signatures.json.
Проверить вручную: Страж → Настройки → «Проверить обновления».


НАСТРОЙКА (один раз, ~5 минут)
------------------------------
1. Зайдите на github.com под аккаунтом Sve1kkk.
   Обязательно включите двухфакторную защиту (Settings → Password and authentication),
   потому что обновления ставятся с правами администратора — аккаунт должен быть защищён.
2. Справа вверху «+» → New repository.
   Имя: Strazh   ·   Public   ·   Create repository.
3. На странице репозитория: «uploading an existing file» и перетащите ВСЁ содержимое
   папки Strazh (включая папку .github — если не видна, включите в Проводнике
   «Вид → Показать → Скрытые элементы»). Нажмите Commit changes.
   Если папка .github не загрузилась: Add file → Create new file, в имени напишите
   .github/workflows/release.yml и вставьте туда содержимое этого файла.
4. Выпустите первую версию (см. ниже) с номером 1.1.0.


ВЫПУСК НОВОЙ ВЕРСИИ
-------------------
1. Замените antivirus.py в репозитории на новый (Add file → Upload files → Commit).
2. Вкладка Actions → слева «Выпустить обновление» → справа Run workflow.
3. Впишите версию больше прошлой (1.1.0 → 1.2.0) и «Что нового» → Run workflow.
4. Через 3-5 минут релиз готов — все установленные Стражи обновятся сами.

ОБНОВЛЕНИЕ БАЗЫ УГРОЗ (без новой версии)
----------------------------------------
Откройте signatures.json в репозитории → карандаш (Edit) → добавьте строку
  "sha256-хэш-файла": "Название угрозы",
→ Commit changes. Хэш файла показывает сам Страж (Сканер → двойной щелчок по файлу).
