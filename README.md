# Страж

Монитор процессов и антивирус для Windows: процессы в реальном времени, поиск подозрительных программ,
автозагрузка, сканер (эвристика + Windows Defender + VirusTotal), карантин, трей и автообновление.

- Установка: скачать архив, запустить `УСТАНОВИТЬ.bat`.
- Новая версия: вкладка **Actions → «Выпустить обновление» → Run workflow**.
- База угроз: файл `signatures.json` — Страж скачивает его сам.
